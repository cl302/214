# FlyDreamAir LoyaltyPlus System

This project is a full-stack web application to manage a loyalty program for FlyDreamAir airline.

## Features
- User Login/Sign Up
- Earn Points Mechanism
- Redeem Rewards with Points
- Cart System
- Payment Simulation
- Clean and Responsive Frontend

## Tech Stack
- Node.js
- Express.js
- HTML/CSS (no frontend frameworks)
- Basic Session Authentication

## How to Run
1. Clone the repo:
    ```bash
    git clone https://github.com/YOUR_USERNAME/flydreamair-loyalty-system.git
    cd flydreamair-loyalty-system
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Start server:
    ```bash
    node server.js
    ```
4. Visit:
    ```
    http://localhost:3000
    ```
